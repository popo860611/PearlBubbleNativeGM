# PearlBubble Native GM v2.4 LAB 候選版

深海龍珠測試面板。安裝包已包含 Lua 資源與 GM 程式，**不需要另外準備脫殼 EXE**。

## 最簡單安裝方式

1. 下載 ZIP，將內容全部解壓到遊戲的 `StarAIO` 資料夾。
2. 關閉遊戲與舊的 GM 視窗。
3. 雙擊 `INSTALL.bat`，看到「安裝完成」即可。
4. 開啟 `StarMJ371.exe`、進入深海龍珠，再雙擊 `START_GM.bat`。

`INSTALL.bat` 會自動使用 BAT 所在資料夾，不必輸入安裝路徑。若 Windows 詢問系統管理員權限，請按「是」。

## 從 v2.3 更新

1. 關閉遊戲與舊 GM。
2. 將新版 ZIP 的全部內容解壓到原本的 `StarAIO` 資料夾，選擇覆蓋同名檔案。
3. 雙擊 `UPDATE.bat`（也可直接再次執行 `INSTALL.bat`）。
4. 看到全部 `PASS` 後，重新開啟遊戲並進入深海龍珠，再執行 `START_GM.bat`。

不必先解除安裝；原始備份與遊戲帳戶資料不會被更新程序刪除。

## 原始 EXE 可以用嗎？

可以。只要資料夾內是支援版本的原始 `StarMJ371.exe`，安裝器會自動：

1. 備份原檔。
2. 解殼。
3. 套用相容補丁。
4. 保留檔名為 `StarMJ371.exe`。

## 其他 BAT

- `CHECK_STATUS.bat`：檢查是否安裝完整；全部顯示 `PASS` 才算成功。
- `CHECK_RUNTIME.bat`：進入深海龍珠後檢查 Lua 橋接是否真的持續運作。
- `RESTORE.bat`：還原安裝前的遊戲檔案。
- `START_GM.bat`：開啟 GM 面板；按 `Insert` 可顯示或隱藏。

## 功能與限制

- 可建立本機演出球、測試碰撞及記錄遊戲封包時間線。
- 「正式白珠 +1（扣1發）」會建立一顆正常計費、由伺服器追蹤的白珠，再移到檯面測試碰撞與掉落；它不是免費加值功能。
- 路徑選項只改變客戶端演出，不代表伺服器正式設獎。
- 本機生成的小珠掉落分數屬於本機顯示，重新進房可能歸零；面板會標示「僅本機（未入帳）」。
- 是否正式入帳，必須以離開房間後的伺服器餘額為準。

## 正式白珠測試（服主授權環境）

1. 進入深海龍珠並等待 GM 面板顯示已連線。
2. 按一次「正式白珠 +1（扣1發）」，不要連按。
3. 等面板顯示 `fire_verified`，再讓白珠自然被推落。
4. `drop_verified` 只代表掉落事件通過；必須顯示 `confirmed` 才代表本次伺服器餘額差符合預期。
5. 離開房間再重新進入，確認餘額仍相同，才可把這次測試記為正式入帳 PASS。

若顯示 `rejected`、`balance_mismatch`、連線異常或重進後餘額回復，均不可視為成功。此功能每次會扣除一發正常押注，預期淨變化為「白珠回獎 − 當前押注」。

## 常見問題

- **顯示找不到 `main.lua`**：必須解壓整個 ZIP，不能只複製 BAT。
- **顯示拒絕存取**：對 `INSTALL.bat` 按右鍵，選「以系統管理員身分執行」。
- **GM 沒連上**：先進入深海龍珠，再執行 `START_GM.bat`。
- **GM 能開但按鈕沒反應**：執行 `CHECK_RUNTIME.bat`。新版通訊檔改放在使用者的 `%TEMP%\PearlBubbleNativeGM`，不再要求遊戲對 `Program Files` 具有寫入權限。
